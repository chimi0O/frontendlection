HTML5: структура и семантика

Каркас документа, семантические теги и их влияние на SEO. Ссылки, изображения, формы. Доступность разметки.

HTML — это структура, а не внешний вид

HTML (HyperText Markup Language) описывает структуру страницы. Он не задаёт внешний вид (это делает CSS) и не добавляет поведение (это JavaScript). HTML отвечает на вопрос: что здесь находится — заголовок, абзац, список, изображение, форма.

Браузер читает HTML сверху вниз и строит из него DOM-дерево — структуру, с которой потом работают стили и скрипты. Если разметка «грязная», всё остальное страдает: CSS сложнее писать, JavaScript — искать элементы, а поисковики — понимать контент.

Каркас документа

Минимальный HTML-документ выглядит так:

Каркас документа
Обязательные элементы: <!DOCTYPE html>, <html lang="ru">, <head> с метаданными и подключением стилей, <body> с видимым контентом.
  • <!DOCTYPE html> — сообщает браузеру, что это HTML5.
  • <html lang="ru"> — корневой элемент, язык страницы.
  • <head> — метаданные: кодировка, viewport, title, подключение CSS.
  • <body> — всё, что видит пользователь.

Семантические теги

Семантика — это смысл. Семантические теги описывают роль блока, а не его внешний вид. Вместо <div> для всего подряд используют <header>, <nav>, <main>, <section>, <article>, <footer>.

Семантическая вёрстка
Использование HTML-тегов по их смыслу: header для шапки, nav для навигации, article для самостоятельной единицы контента, footer для подвала. Улучшает доступность и SEO.

Основные теги:

  • <header> — шапка страницы или раздела.
  • <nav> — блок навигации.
  • <main> — основное содержимое (один на страницу).
  • <section> — смысловой раздел.
  • <article> — самостоятельная единица контента.
  • <aside> — боковой блок.
  • <footer> — подвал.

Семантика и SEO

Поисковые системы читают HTML так же, как скринридеры: по тегам. Семантическая разметка помогает роботам понять, где заголовок, где основной текст, а где навигация. Это влияет на сниппеты, индексацию и поведенческие факторы.

Что важно для рекламного сайта:

  • Один H1. Главный заголовок страницы — один и содержит ключевой запрос.
  • Иерархия H2–H6. Подзаголовки выстроены по уровням.
  • Alt у изображений. Описание картинок для поиска и доступности.
  • Ссылки с понятным текстом. Не «нажмите здесь», а «оставить заявку».
  • Микроразметка. Schema.org для товаров, отзывов, организаций.
Важно

Семантика — не «для галочки». Правильная разметка помогает и людям (скринридеры, клавиатура), и роботам (SEO), и разработчикам (понятный код).

Ссылки

Ссылка — ключевой элемент веба. Тег <a> с атрибутом href. Важные нюансы:

  • Текст ссылки. Должен объяснять, куда она ведёт.
  • target="_blank". Открывает в новой вкладке — использовать осознанно.
  • rel="noopener". Безопасность при target="_blank".
  • Доступность. Ссылка доступна с клавиатуры и имеет видимый фокус.

Изображения

Тег <img> с обязательным атрибутом alt. Изображение — контент, а не украшение. Что важно:

  • alt. Описание для скринридеров и поиска.
  • width и height. Предотвращают «прыжки» контента при загрузке.
  • loading="lazy". Ленивая загрузка для изображений ниже первого экрана.
  • srcset. Разные версии для разных экранов.
  • Формат. WebP/AVIF для фото, SVG для иконок.

Формы

Форма — главный инструмент конверсии на рекламном сайте. Тег <form> с полями <input>, <textarea>, <select> и кнопкой <button>.

Что важно для форм:

  • Label. Каждое поле — с подписью <label>.
  • Типы input. email, tel, number — для мобильных клавиатур.
  • Валидация. required, pattern, minlength — на стороне браузера.
  • Доступность. Поля доступны с клавиатуры, ошибки читаются скринридером.
  • Минимум полей. Каждое лишнее поле снижает конверсию.
Для рекламы

HTML — фундамент. Дизайнер, который понимает разметку, проектирует макеты, которые проще верстать, и не создаёт «дизайн, который невозможно реализовать».

Итог

HTML5 — язык структуры. Семантические теги, правильные ссылки, изображения с alt и доступные формы — база, без которой не работает ни SEO, ни конверсия, ни доступность.
